# Systolic Arrays &mdash; The Matmul Engine Inside the TPU

The 47-year history of systolic arrays from Kung &amp; Leiserson's 1978 paper through CMU Warp / Intel iWarp, the 1990s decline, and the TPU revival in 2015. Three dataflows (weight-stationary, output-stationary, row-stationary), why TPU is weight-stationary, and how a 256&times;256 array maps a matmul. Includes an interactive 8&times;8 wavefront visualiser.

**Live site:** https://brendanjameslynskey.github.io/Google_TPU_03_Systolic_Arrays/

Part of the [Google TPUs series](https://github.com/BrendanJamesLynskey/LLMs#hardware--inference).
